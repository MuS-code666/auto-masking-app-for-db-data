| 質問 | 回答 | 設計への反映 |
|---|---|---|
| データの規模 | 月次ファイル3種×5か月（1,000行・20列・備考約20文字）、マスタ5種×1（100行・10列・備考なし） | 性能の基準ケースと暫定目標を設定（[08_performance_plan.md](08_performance_plan.md) 0章）。備考のLLM検査は異なる値ごと・まとめて問い合わせる方式に |
| Excel の実態 | 数式はよく使われる。それ以外はまれ | 数式の文字列定数の置換・キャッシュ値処理を初期版の重点に（[06_file_support.md](06_file_support.md) 4.1）。受入シナリオ S15 を追加。ピボット等は検出して停止のまま |
| 保存データの保護 | ディスク暗号化・アプリ独自の暗号化とも求められていない | 初期版はアプリ独自の暗号化なし。フォルダのアクセス権と画面表示で注意喚起（[07_verification_output.md](07_verification_output.md) 6.3） |
| 技術構成 | Python + PySide6 で可 | 採用確定（[02_architecture.md](02_architecture.md)） |

## 2. 未決事項と推奨初期値

特に指示がなければ、以下の推奨初期値で実装を進める。

| No | 事項 | 推奨初期値 | 備考 |
|---|---|---|---|
| 1 | 原本をプロジェクトに複製するか | 複製する（読み取り専用、ハッシュ管理） | 再実行・検証の再現性のため。参照のみの設定も可能にする |
| 2 | 名称番号の桁数 | 4桁、超過時は自動で桁を伸ばす | 想定規模（対象 約500件）では4桁で十分 |
| 3 | 変換後コードの形式 | 元と同じ長さ・文字種。元コードと重ならない範囲から連番 | [05_algorithms.md](05_algorithms.md) 3.2 |
| 4 | 住所・電話・メールの既定処理 | 内容削除 | 置換を選ぶと形式を保ったダミー値 |
| 5 | 住所の粒度保持 | 初期版は対象外（全体置換または削除） | 都道府県・市区町村まで残す機能は後続 |
| 6 | 自由記述で自動置換しない短い語 | 2文字以下、数字のみ4桁以下 | 要確認として人が判断 |
| 7 | 数式キャッシュ値 | 対応表で置換＋開いたときに再計算を設定 | 文字列操作系の数式は警告 |
| 8 | 数式の文字列定数 | 登録語句と完全一致なら置換、部分一致・ワイルドカードは停止 | [06_file_support.md](06_file_support.md) 4.1 |
| 9 | コメント | 停止し「除去して出力」を選択可能 | まれとの回答のため置換対応は後続 |
| 10 | 文書プロパティ・サムネイル | 初期化・除去を既定 | |
| 11 | 他プロジェクトで取込済みのファイルの警告 | 有効（ファイルのハッシュのみを共通の索引に保存） | |
| 12 | LLM の実行基盤 | **決定（2026-11-04）**：OpenVINO GenAI。既定の処理装置は GPU（CPU・NPU も選択可） | 実機（Core Ultra 7 258V）で CPU・GPU・NPU の動作を確認。02 章 1.4 |
