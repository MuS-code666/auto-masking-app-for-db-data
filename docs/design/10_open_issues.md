# 10 未決事項と推奨初期値・追加質問

## 1. 未決事項と推奨初期値

| No | 事項 | 推奨初期値 | 備考 |

## 2. 追加の質問（重要なものに限定）

1. **データの規模**：1回に扱うファイル数、1ファイルあたりのおおよその行数・列数、自由記述（備考）列の量の目安を教えてください。性能目標と、LLM で自由記述を全件検査するかどうかの判断に使います。
2. **Excel ファイルの実態**：対象の .xlsx に、ピボットテーブル、グラフ、外部リンク、コメント、数式（VLOOKUP 等）はよく含まれますか。初期版で停止にしている機能のうち、どれの対応を優先すべきかの判断に使います。
3. **保存データの保護**：社内ルールで、端末のディスク暗号化（BitLocker 等）が必須になっていますか。また、アプリ独自の暗号化（パスワード入力が必要になる）が求められますか。
4. **技術構成**：Python + PySide6 で進めてよいですか。社内配布で .NET が望ましい等の制約があれば教えてください。
